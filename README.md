RandomArrayGenerator
A simple C# program to generate an array filled with random values.

Features
Populate an array with random numbers using the Random class.
Display the array in the console.
Easy to customize array length and number range.
Example Output
Random array values: 23 7 45 89 12 34 56 78 90 1

How to Use
Clone the repository.
Open the project in Visual Studio or any C# IDE.
Run the program.
Modify the array length or random number range in the code if desired.
